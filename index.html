Cómo instalar las aplicaciones

Puedes añadir estas aplicaciones a la pantalla de inicio de tu móvil o tableta para abrirlas fácilmente. Primero, abre la aplicación que quieras instalar desde una de las tarjetas de arriba.

Android

  1. Abre la aplicación en Google Chrome.
  2. Pulsa el menú de tres puntos (⋮).
  3. Selecciona «Instalar aplicación» o «Añadir a pantalla de inicio», según la opción disponible.
  4. Confirma la acción. Encontrarás el icono en la pantalla de inicio o en la lista de aplicaciones.

iPhone y iPad (iOS)

  1. Abre la aplicación en Safari.
  2. Pulsa el botón Compartir (un cuadrado con una flecha hacia arriba).
  3. Selecciona «Añadir a pantalla de inicio». Si no aparece, búscala entre las acciones disponibles.
  4. Pulsa «Añadir». El icono aparecerá en la pantalla de inicio.

Importante: La opción «Instalar» puede variar según el navegador y la configuración de cada aplicación. Añadirla a la pantalla de inicio no garantiza que funcione sin conexión a Internet; esto depende de cómo esté desarrollada cada aplicación.
